# FF14 XHB練習ツール 計画書

## 概要

コントローラー向けのXHB（クロスホットバー）練習ツール。単一HTMLファイルで動作。

**想定ユーザー:** コントローラーのボタンで狙った場所のスキルを起動するのに慣れない人

---

## XHBの構造

XHBは左右2セット × 8スロット = 計16スロット。

| セット | トリガー | ボタン |
|--------|---------|--------|
| 左セット | L2長押し | ↑←↓→ ＋ □△○× |
| 右セット | R2長押し | ↑←↓→ ＋ □△○× |

---

## ゲームの流れ

1. 画面にXHBレイアウトを表示
2. ランダムなスロットが光る
3. ユーザーが対応するボタン（L2/R2 + 方向/フェイス）を押す
4. 正解/不正解を表示してスコアを記録
5. 次のスロットへ

---

## 技術構成

- **単一HTMLファイル**（CSS・JSインライン）
- キーボードで疑似入力（矢印キー＋WASD＋ZXCVなど）
- Gamepad API対応（実物のコントローラー接続時）

---

## キーボードマッピング

| PADボタン | キーボード |
|-----------|-----------|
| L2        | 左Shift（長押し） |
| R2        | 右Shift（長押し） |
| ↑←↓→    | 矢印キー |
| □         | Z |
| △         | X |
| ○         | C |
| ×         | V |

## 実装ステップ

### Step 1: HTMLの骨格とXHBレイアウト
- `index.html` を作成
- XHBの16スロットをCSSグリッドでレイアウト
- 左セット・右セットを視覚的に分ける

### Step 2: スロットのハイライト機能
- ランダムにスロットを選ぶJS関数を実装
- 選ばれたスロットをCSSでハイライト（光らせる）
- 「今押すボタン」テキストを更新

### Step 3: キーボード入力の受付
- `keydown` / `keyup` イベントで L2/R2（Shift）の長押し状態を管理
- 方向キー・フェイスボタンキーと組み合わせて入力を判定

### Step 4: 正誤判定とフィードバック
- 入力とハイライト中スロットを比較
- 正解なら緑フラッシュ＋スコア加算
- 不正解なら赤フラッシュ
- 一定時間後に次の問題へ

### Step 5: スコア・統計表示
- 正解数 / 出題数を表示
- セッション終了ボタン＋リセット機能

### Step 6: Gamepad API対応（オプション）
- `gamepadconnected` イベントで実機コントローラーを検出
- L2/R2トリガーと各ボタンをポーリングで読み取り
- キーボード入力と共存させる

### Step 7: 仕上げ・調整
- FF14っぽいビジュアル（ダークテーマ、ゴールドアクセント）
- アニメーション調整
- README作成
