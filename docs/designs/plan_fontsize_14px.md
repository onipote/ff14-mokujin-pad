# Plan: フォントサイズ引き上げ（12px未満 → 14px目標）

## Context
`styles/main.css` に 8〜11px の小さいテキストが多数存在し、視認性が低い。  
ユーザー要望：12px未満の文字を 14px 目安に引き上げる。スペース制約のある要素は可能な範囲で段階的に増やす。タイトル画面のサブタイトルも合わせて見直す。

---

## 変更対象ファイル
`styles/main.css` のみ

---

## 変更しない項目

- `.screen-panel::before/after` の 10px→11px は最小増加。14px にすると隅装飾として目立ちすぎる。
- `.heatmap-pct` は 32px スロット内に収める必要があるため 10px 止まり。
- `.copyright-notice` は意図的に控えめなデザインのため 11px 止まり。

---

## 検証方法

1. `npm start` でサーバー起動
2. ブラウザで確認：
   - **タイトル画面**：サブタイトル文字サイズ・バランス確認
   - **ゲーム中画面**：スコア/コンボラベル・ヘッダー・XHB スロット
   - **リザルト画面**：判定数・ランク・スコア・ヒートマップ
   - **設定UI**：難易度ボタン・設定ラベル
   - **ポーズ画面**：パッドヒント
3. レイアウト崩れがないことを確認（特に XHB スロット・ヒートマップ・ヘッダーバッジ）
