# 設計: スクロールバー抑制

## 問題

ブラウザウィンドウが狭いとき（縦・横どちらかが小さい場合）に、ページレベルのスクロールバーが表示される。  
ゲームはゲームパッド必須・固定レイアウトのため、スクロールは不要であり、見た目上も違和感がある。

## 解決方針

`html` 要素に `overflow: hidden` を設定してブラウザウィンドウレベルのスクロールバーを完全に抑制する。

## 影響範囲

| 要素 | 影響 |
|------|------|
| ページ全体のスクロールバー | 非表示になる（意図通り） |
| `#screen-gameover .screen-panel` | `overflow-y: auto` + `max-height: calc(100vh - 32px)` により**内部スクロールは維持**される |
| `body` | 変更なし |

## 変更ファイル

- `styles/main.css`

## 変更内容

```css
/* ===== Reset ===== */
html {
  overflow: hidden;
}
```

リセットセクションの先頭に追加。

## 検証方法

- ブラウザウィンドウを 400px 幅や 500px 高さなど小さいサイズに変更
- スクロールバーが表示されないことを確認
- ゲームオーバー画面でコンテンツが多い場合、パネル内部でスクロールできることを確認
