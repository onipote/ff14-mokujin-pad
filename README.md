# PAD-MOKUJIN

FF14のXHB（クロスホットバー）操作を練習するツールです。

## 概要

XHBのスロットがランダムに光り、FF14のリキャストゲージ風のアニメーションが始まります。  
ゲージが回り終わるタイミングで正しいボタンを押してください。  
**コントローラー（PS4/PS5）必須です。** ゲーム開始前にコントローラーを接続してください。

## 起動方法

```bash
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

> **注意**: コントローラー入力にはlocalhostまたはHTTPS環境が必要です。

## 操作方法

### コントローラー（PS4/PS5）

FF14と同じ操作です。

- **L側XHB**: L1またはL2を押しながら D-pad / △□○×
- **R側XHB**: R1またはR2を押しながら D-pad / △□○×
- **AOE回避（左パネル）**: 警告が出たらLスティックを安全地帯方向に倒し続ける
- **視線ギミック（右パネル）**: 目アイコンが出現したら、Rスティックで枠を動かして目を枠の外に出し続ける

### 画面操作

| 画面 | ボタン | 動作 |
|------|--------|------|
| タイトル | ←→ | DIFFICULTY 変更 |
| タイトル | ↑↓ | DIFFICULTY ⇔ START 間の移動 |
| タイトル | ✕ または OPTIONS | ゲーム開始 |
| ゲーム中 | OPTIONS | 一時停止 |
| ポーズ | OPTIONS または ✕ | ゲーム再開 |
| ポーズ / ゲームオーバー | ↑↓ で選択・✕ で決定 | 続ける / メニューへ戻る |

## 難易度

| 難易度 | GCD時間 | バースト閾値 | 1ヒットスコア |
|--------|--------|------------|-------------|
| 遅い   | 3.5秒  | コンボ10   | 350pt       |
| 普通   | 2.5秒  | コンボ15   | 250pt       |
| 速い   | 1.5秒  | コンボ20   | 150pt       |

## ルール

制限時間は90秒。ミスするたびに残り時間が -5秒になります。TIME UPでゲーム終了です。

### 判定

| 判定 | 条件 | 効果 |
|------|------|------|
| ◎ GREAT | リキャストゲージ 75%〜100% の間に入力 | コンボ++ / スコア加算 |
| ○ GOOD  | ゲージ 100%〜 猶予時間内に入力 | コンボ維持 / スコア加算 |
| ✕ MISS  | 猶予時間切れ | コンボ0リセット / 時間-5s |

- ゲージが100%に達すると次のスロットが表示され始める（FF14のGCDキューイングに相当）
- **誤ったボタン**を押してもペナルティなし（白フラッシュのみ）
- **早押し**（75%未満）もペナルティなし（白フラッシュのみ）

### コンボ・バーストタイム

- **GREAT** を連続で決めるとコンボが蓄積される（GOOD では増えない、MISS でリセット）
- **コンボ10** → 残り時間 +2秒
- **コンボが閾値（難易度依存）** → **バーストタイム**（10秒間）が発動
  - GCDの回転速度が 1.4倍になる
  - 獲得スコアが 2倍になる
  - バースト中のミスはコンボをリセットしない
  - バースト終了後はコンボが0に戻る

## スティックギミック

XHBの練習中、左右のパネルでランダムにギミックが発生します。判定まで3秒の猶予があります。

### 左パネル：AOE回避

以下の8種類のAoEパターンがランダムに出現します。各パターンのサイズは±15%程度ランダムに変化します。

| パターン | 内容 |
|--------|------|
| 左半面 / 右半面 / 上半面 / 下半面 | フィールド半分を覆う大きな四角 |
| 大円 | ランダムな位置の大きな円形AoE |
| 小円（複数） | 2〜4個の小さな円形AoEが同時に出現（重なりあり） |
| 横帯 | 全幅の帯状AoE（縦位置ランダム） |
| 縦帯 | 全高の帯状AoE（横位置ランダム） |

- **枠の色**: ギミック発生中は黄色の枠に変化
- **AOEゾーンの色 / カーソルの色**: カーソルが危険エリア内→赤、外→緑にリアルタイム変化
- 判定時にカーソルが危険エリア内にいると被弾（時間-5s）

### 右パネル：視線ギミック

カメラ操作のイメージです。Rスティックで移動範囲の約1/4サイズの長方形フレームを動かします。

- **枠の色**: ギミック発生中は黄色の枠に変化
- 赤黒い目アイコンがフィールド内のランダムな位置に出現
- **フレームの色**: 目の中心がフレーム内→オレンジ、外→緑にリアルタイム変化
- 判定時に目の中心がフレーム内に入っていると被弾（時間-5s）
- フレームはフィールドの端からはみ出さない
