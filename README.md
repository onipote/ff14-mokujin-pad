# MOKUJIN PAD ─ 指酷（しっこく）のクロスホットバー

コントローラーでのFF14のXHB（クロスホットバー）操作が難しい！
LとRがややこしい！ぱっと押したいボタンが押せない！...という方のための練習ツールです。

## 🎮 今すぐプレイ！

ダウンロードやインストールの必要はありません。
PCにコントローラーを接続し、以下のリンクをクリックするだけですぐにブラウザで遊べます！

👉 **[MOKUJIN PADをプレイする（GitHub Pages）](https://onipote.github.io/ff14-mokujin-pad/)**

## 🧭 ゲーム概要

XHB上で次々と光るボタンを押しましょう！（※モンハン持ち推奨）
制限時間60秒のタイムアタックゲームです。

ボタンはリキャスト75%を超えると先行入力を受け付けます。できるだけ狙いましょう。
入力が遅すぎると失敗になり、制限時間が減ってしまうので注意！

ボタンだけでなくスティック操作も必要です。
左画面にAoEが現れたら、左スティックで回避してください。
右画面に探検アイコンが現れたら、右スティックで枠を動かしてアイコンを枠の中に取り込んでください。

先行入力を連続成功するとリミットゲージが溜まります。
リミットゲージ1本溜まるごとに制限時間がわずかに伸びます。

また、リミットゲージ最大の状態で入力成功すると、リミットブレイク発動！
GCDが早くなりますが、得点が2倍になるボーナスタイム！

## 🕹️ 操作方法

### 1. コントローラー操作（基本はFF14と共通）

- **L側XHB入力**: `L1` または `L2` を押しながら ＋ `方向キー` または `Ⓧ / ❑ / 𝛥 / ◯`
- **R側XHB入力**: `R1` または `R2` を押しながら ＋ `方向キー` または `Ⓧ / ❑ / 𝛥 / ◯`
- **AoE回避（左パネル）**: 警告エリアが出たら、`Lスティック` を倒して安全地帯（緑色の状態）へ逃げ続ける
- **頭割りギミック（右パネル）**: **頭割りマーカー**が出現したら、`Rスティック` で四角い枠を動かし、マーカー中心を**枠の中に取り込む**

### 2. 画面・メニュー操作

| 場面                | コントローラーのボタン       | 動作                                                |
| ------------------- | ---------------------------- | --------------------------------------------------- |
| **タイトル**        | `←` `→`                      | 難易度（DIFFICULTY）の変更                          |
| **タイトル**        | `↑` `↓`                      | 設定項目 ⇔「START」ボタンの移動                     |
| **タイトル**        | `Ⓧ` または `OPTIONS`         | ゲーム開始                                          |
| **ゲーム中**        | `OPTIONS`                    | 一時停止（ポーズ）                                  |
| **ポーズ中**        | `OPTIONS`                    | ゲーム再開                                          |
| **ポーズ / 終了後** | `↑` `↓` で選択 ／ `Ⓧ` で決定 | 「続ける（RETRY）」または「タイトルに戻る（MENU）」 |

## ⚔️ バトルルールと特殊システム

制限時間は**60秒**。ミスをすると残り時間が減っていきます。時間内にどこまでスコアを伸ばせるかのタイムアタックです！

### 1. アクション入力の評価

タイミングよくボタンを押せたかどうかに応じて、以下の判定が行われます。

| 判定        | 入力タイミング                              | 効果・ボーナス                            |
| ----------- | ------------------------------------------- | ----------------------------------------- |
| **◎ GREAT** | ゲージが **75% 〜 100%** の間（ジャスト！） | 基本スコア **+200pt**                     |
| **◯ GOOD**  | ゲージが **100% を過ぎてから** 猶予時間内   | スコア加算（最大100ptから時間経過で減衰） |
| **✕ MISS**  | ボタンを押し損ねる、またはギミックに被弾    | **残り時間 -5秒**                         |

- 💡 **早押し・お手つきはノーペナルティ！**
  ゲージが75%に達する前に押してしまったり、全く違うボタンを押してしまっても減点やミスのペナルティはありません（画面が白くフラッシュするだけです）。焦らずに次のジャストタイミングを狙いましょう。
- 💡 **GCDキューイング（先行入力）を再現！**
  ゲージが100%に達すると、本家FF14の先行入力（スキルキューイング）のように次のスロットが即座に表示され始めます。

### 2. LIMIT BREAK（リミットブレイク）＆ バーストタイム

画面左上には3分割された **LIMIT BREAK（LB）ゲージ** があります。
**GREAT** を連続で決めることでゲージが溜まっていきます。（※GOODでは増えず、MISSをすると全リセットされます）

- **ゲージ1個目完成**: 残り時間 **+1秒**
- **ゲージ2個目完成**: 残り時間 **+2秒**
- **ゲージ3個目完成**: 残り時間 **+3秒**
- **3個完成後にさらにGREAT成功**: 究極の **「バーストタイム（10秒間）」** が発動！

> 🌟 **バーストタイム中の超絶メリット**
>
> 1. GCDの回転速度（ゲームスピード）が **1.4倍** に加速！
> 2. 獲得できるスコアがすべて **2倍** に跳ね上がる！
> 3. ミスをしても残り時間が減らない（無敵状態）！

## 🛡️ 難易度（コース）選択

自分のレベルに合わせて3つの難易度から挑戦できます。初心者でも安心して始められる設計です。

- **やさしい**：GCD 3.5s。まずはボタン配置とギミックに慣れたい初心者に。
- **ふつう**：GCD 2.5s。本家FF14と全く同じ、最も標準的なレギュレーション。
- **むずかしい**：GCD 1.5s。高速化されたスキル回しに指先が追いつくか！？上級者向け。

## 👁️ 襲いかかるギミック

XHB入力中、左右のパネルに以下のギミックがランダムに発生します。アラートが出てから**3秒以内**に対応しなければ被弾し、残り時間が大幅に減少（-5秒）します。

### 左パネル：AoE（範囲攻撃）回避

フィールドを覆う危険エリア（赤色）が迫ります。Lスティックでカーソルを動かし、**安全地帯（緑色）**に避難し続けてください。

- **ギミックの種類**: 左右・上下の半面攻撃、巨大な円形攻撃、複数の小円、格子状の帯攻撃、放射状の扇形攻撃など。

### 右パネル：頭割りギミック（集合）

**頭割りマーカー**が枠の外にランダムスポーンします。Rスティックでフレーム（四角枠）を動かし、マーカーの中心を枠の**中に取り込んで**ください。

- フレームは**マーカー中心が枠外のとき赤色**、**枠内に入ると緑色**に変わります。
- 猶予時間（3秒）内にマーカーを枠内に収められなかった場合、被弾し残り時間 -5秒となります。

## 📊 充実の自己分析機能（リザルト）

ゲーム終了後は、あなたのプレイを徹底的に分析したリザルト画面が表示されます。

- **総合評価ランク（SSS〜C）**
  理論上の最高得点を100%とした達成率から、あなたの腕前をランク付け。さらにあなたの実力を**「DPS換算（XX%）」**して表示します。
- **弱点ヒートマップ**
  XHBのどのボタンが苦手か、ボタンごとの「GREAT成功率」が視覚的にわかるマップです。
  - **緑色**：GREAT率100%（完璧に指に馴染んでいる得意ボタン）
  - **赤色**：GREAT率0%（押し間違いやタイミングミスが多い苦手ボタン）

何度も挑戦して、苦手なボタン（赤色）を克服し、オールグリーンでの**SSSランク**を目指しましょう！
