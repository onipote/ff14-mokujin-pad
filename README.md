# PAD MASTERY ─ 覚醒のクロスホットバー

FF14のXHB（クロスホットバー）操作を練習するツールです。

## 概要

XHBのスロットがランダムに光り、FF14のリキャストゲージ風のアニメーションが始まります。  
ゲージが回り終わるタイミングで正しいボタンを押してください。  
**コントローラー（PS4/PS5）必須です。** ゲーム開始前にコントローラーを接続してください。

## 起動方法

```bash
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

> **注意**: コントローラー入力にはlocalhostまたはHTTPS環境が必要です。

## 操作方法

### コントローラー（PS4/PS5）

FF14と同じ操作です。

- **L側XHB**: L1またはL2を押しながら D-pad / △□○×
- **R側XHB**: R1またはR2を押しながら D-pad / △□○×
- **AOE回避（左パネル）**: 警告が出たらLスティックを安全地帯方向に倒し続ける
- **視線ギミック（右パネル）**: 目アイコンが出現したら、Rスティックで枠を動かして目を枠の外に出し続ける

### 画面操作

| 画面 | ボタン | 動作 |
|------|--------|------|
| タイトル | ←→ | DIFFICULTY 変更 |
| タイトル | ↑↓ | DIFFICULTY ⇔ START 間の移動 |
| タイトル | ✕ または OPTIONS | ゲーム開始 |
| ゲーム中 | OPTIONS | 一時停止 |
| ポーズ | OPTIONS または ✕ | ゲーム再開 |
| ポーズ / ゲームオーバー | ↑↓ で選択・✕ で決定 | 続ける / メニューへ戻る |

## 難易度

| 難易度 | GCD時間 | 1ゲージ必要大成功数 | 1ヒットスコア |
|--------|--------|------------------|-------------|
| 遅い   | 3.5秒  | 3回              | 350pt       |
| 普通   | 2.5秒  | 5回              | 250pt       |
| 速い   | 1.5秒  | 6回              | 150pt       |

## ルール

制限時間は60秒。ミスするたびに残り時間が -5秒になります。TIME UPでゲーム終了です。

### 判定

| 判定 | 条件 | 効果 |
|------|------|------|
| ◎ GREAT | リキャストゲージ 75%〜100% の間に入力 | コンボ++ / スコア加算 |
| ○ GOOD  | ゲージ 100%〜 猶予時間内に入力 | コンボ維持 / スコア加算 |
| ✕ MISS  | 猶予時間切れ | コンボ0リセット / 時間-5s |

- ゲージが100%に達すると次のスロットが表示され始める（FF14のGCDキューイングに相当）
- **誤ったボタン**を押してもペナルティなし（白フラッシュのみ）
- **早押し**（75%未満）もペナルティなし（白フラッシュのみ）

### LIMIT BREAKゲージ・バーストタイム

画面左上の **LIMIT BREAKゲージ** は3分割されており、**GREAT** を連続で決めることで段階的に蓄積されます（GOOD では増えない、MISS で現ゲージの進捗リセット）。

| ゲージ完成 | 効果 |
|-----------|------|
| 1個目完成 | 残り時間 **+1秒** |
| 2個目完成 | 残り時間 **+2秒** |
| 3個目完成 | 残り時間 **+3秒** |
| 3個目完成後にさらにGREAT | **バーストタイム**（10秒間）発動 |

**バーストタイム中：**
- GCDの回転速度が 1.4倍になる
- 獲得スコアが 2倍になる
- ミスしてもコンボをリセットしない
- バースト終了後はゲージが0に戻る

## リザルト画面

ゲーム終了後に以下の情報が表示されます。

### 総合評価（ランク）

全スロットをノーバーストで全GREAT時のスコアを100%として達成率を算出し、ランクを表示します。

| ランク | 達成率 | 色 |
|--------|--------|-----|
| SSS | 99〜100% | ピンク |
| SS  | 95〜98%  | オレンジ |
| S   | 75〜94%  | 紫 |
| A   | 50〜74%  | 青 |
| B   | 25〜49%  | 緑 |
| C   | 0〜24%   | 灰 |

- **DPS XX%**: 達成率をDPS風に表示
- バーストタイム中の2倍スコアは達成率に加算される（100%でクランプ）

### スコア・判定内訳

- 最終スコアとベストスコアを横並びで表示
- GREAT / GOOD / MISS の判定回数内訳

### 弱点マップ

XHBの全ボタンの「大成功率（GREAT率）」をヒートマップで可視化します。

- **緑**: GREAT率100%（得意なボタン）
- **赤**: GREAT率0%（苦手なボタン・ミスが多い）
- 一度も出現しなかったボタンは無色で表示なし

## スティックギミック

XHBの練習中、左右のパネルでランダムにギミックが発生します。判定まで3秒の猶予があります。

### 左パネル：AOE回避

以下の8種類のAoEパターンがランダムに出現します。各パターンのサイズは±15%程度ランダムに変化します。

| パターン | 内容 |
|--------|------|
| 左半面 / 右半面 / 上半面 / 下半面 | フィールド半分を覆う大きな四角 |
| 大円 | ランダムな位置の大きな円形AoE |
| 小円（複数） | 2〜4個の小さな円形AoEが同時に出現（重なりあり） |
| 扇形 | 中心から放射状に広がる扇形。中心角30〜60度（ランダム）の4本が90度ずつ同時に出現 |
| 帯 | 同じ幅の帯を2本同時表示。横×2 / 縦×2 / 横+縦のいずれか。同方向の場合は重ならない |

- **枠の色**: ギミック発生中は黄色の枠に変化
- **AOEゾーンの色 / カーソルの色**: カーソルが危険エリア内→赤、外→緑にリアルタイム変化
- 判定時にカーソルが危険エリア内にいると被弾（時間-5s）

### 右パネル：視線ギミック

カメラ操作のイメージです。Rスティックで移動範囲の約1/4サイズの長方形フレームを動かします。

- **枠の色**: ギミック発生中は黄色の枠に変化
- 赤黒い目アイコンがフィールド内のランダムな位置に出現（枠の中央付近には出現しない）
- 約1/3の確率で目アイコンがフレームの内側に出現する（即座にフレームを移動する必要がある）
- **フレームの色**: 目の中心がフレーム内→オレンジ、外→緑にリアルタイム変化
- 判定時に目の中心がフレーム内に入っていると被弾（時間-5s）
- フレームはフィールドの端からはみ出さない
