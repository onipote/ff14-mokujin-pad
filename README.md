# PAD-MOKUJIN

FF14のXHB（クロスホットバー）操作を練習するツールです。

## 概要

XHBのスロットがランダムに光り、FF14のリキャストゲージ風のアニメーションが始まります。  
ゲージが回り終わるタイミングで正しいボタンを押してください。  
**コントローラー（PS4/PS5）必須です。** ゲーム開始前にコントローラーを接続してください。

## 起動方法

```bash
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

> **注意**: コントローラー入力にはlocalhostまたはHTTPS環境が必要です。

## 操作方法

### コントローラー（PS4/PS5）

FF14と同じ操作です。

- **L側XHB**: L1またはL2を押しながら D-pad / △□○×
- **R側XHB**: R1またはR2を押しながら D-pad / △□○×
- **AOE回避**: 警告が出たらスティックを安全地帯方向に倒し続ける

### 画面操作

| 画面 | ボタン | 動作 |
|------|--------|------|
| タイトル | ↑↓ | MODE / DIFFICULTY / START 間の移動 |
| タイトル | ←→ | 現在のセクション内で選択を変更 |
| タイトル | ✕ または OPTIONS | ゲーム開始 |
| ゲーム中 | OPTIONS | 一時停止 |
| ポーズ | OPTIONS または ✕ | ゲーム再開 |
| ポーズ / ゲームオーバー | ↑↓ で選択・✕ で決定 | 続ける / メニューへ戻る |

## ゲームモード

| モード | 内容 |
|--------|------|
| フリーモード | 時間制限なし。HP0になっても回復して続行。倒した数・ミス数を表示 |
| スコアアタック | 60秒以内に高スコアを目指す。HP0でゲームオーバー |

## 難易度

| 難易度 | 制限時間 |
|--------|---------|
| 遅い | 4秒 |
| 普通 | 2.5秒 |
| 速い | 1.5秒 |

## ルール

- スロットが光ると同時に**円形リキャストゲージ**が回り始める（白の扇形アニメーション）
- ゲージが75%以上回ったら入力が有効になる（それ以前は白フラッシュのみ）
- **ゲージが100%に達すると、次のスロットが表示されて次のゲージが開始する**（FF14のGCDキューイングに相当）
- ゲージが100%到達後も、**さらに1回分（ゲージ200%相当）** の猶予があれば正しいボタンを押せる
- ゲージ200%まで未入力 → 時間切れ（HP-1）
- 猶予ウィンドウ内で正解すると、次のスロットはすでに進んだゲージ状態で引き継がれる
- **誤ったボタン**を押してもペナルティなし（そのボタンが白く光るのみ）
- HP0時の挙動はモードによって異なる（フリーモードはHPを全回復して続行、スコアアタックはゲームオーバー）
- コンボが続くとスコア倍率が上昇（最大5倍）
- 警告エリアが出たらスティックで安全地帯に移動してAOEを回避
