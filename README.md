# PAD-MOKUJIN

FF14のXHB（クロスホットバー）操作を練習するツールです。

## 概要

XHBのスロットがランダムに光るので、正しいボタンを制限時間内に押してください。  
**コントローラー（PS4/PS5）必須です。** ゲーム開始前にコントローラーを接続してください。

## 起動方法

```bash
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

> **注意**: コントローラー入力にはlocalhostまたはHTTPS環境が必要です。

## 操作方法

### コントローラー（PS4/PS5）

FF14と同じ操作です。

- **L側XHB**: L2を押しながら D-pad / △□○×
- **R側XHB**: R2を押しながら D-pad / △□○×
- **AOE回避**: 警告が出たらスティックを安全地帯方向に倒し続ける

## ゲームモード

| モード | 内容 |
|--------|------|
| フリーモード | 時間制限なし。倒した数・ミス数を表示 |
| スコアアタック | 60秒以内に高スコアを目指す |

## 難易度

| 難易度 | 制限時間 |
|--------|---------|
| 遅い | 4秒 |
| 普通 | 2.5秒 |
| 速い | 1.5秒 |

## ルール

- 光ったスロットを制限時間内に押す → 木人にダメージ
- 時間切れ → 自分がAOEを受けてHP-1
- HP0でゲームオーバー
- コンボが続くとスコア倍率が上昇（最大5倍）
- 警告エリアが出たらスティックで安全地帯に移動してAOEを回避
